# 统一消费者小程序（首个增量）

当前仓库没有真实微信小程序工程，因此先提供 `/consumer` 浏览器预览，验证统一多商家上下文、品牌主题、商品/服务卡和 AI 接力路径。真实小程序页面、微信登录、`wx.onAgentHandoff` 和发布流程属于后续 M1/M4，状态为未接通。

## 已落地的 Mock 主链路

```text
活动入口上下文
→ 指定商家/门店
→ 商品与服务列表
→ 加入购物车或选择预约
→ 创建待支付订单草稿
→ 生成一次性 Handoff 引用
```

订单金额、库存、档期、租户归属均由 `src/domain/commerce.js` 的确定性契约校验。页面会明确显示“演示模式 / 未接入支付”，不展示虚假的支付成功。
