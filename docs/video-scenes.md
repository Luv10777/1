# 视频创作 · 创作场景

视频工作台左侧有单独的「创作场景」一栏。点开场景面板选一张卡片，这一栏就显示选定的场景。
场景给视频模型和方案模型补一段「分镜参考」，告诉它们这类视频通常怎么开头、中间讲什么、怎么收尾。
完整产品需求见 PRD 文档《视频创作 · 创作场景模块 PRD》。本文只记实现边界。

## 一期范围

- 6 个场景：自由创作（默认，不附任何内容）、电商带货、本地生活探店、活动引流、品牌宣传、剧情短片。
- 场景和分镜参考内置在后端 `VideoScenes`。改文案要发后端；二期再搬进数据库由管理后台维护。
- 分镜参考只在服务端使用，`GET /api/video/scenes` 只返回名称、一句话用途、图标、占位文字和素材提示。
- 场景不改比例、时长、分辨率和模型。
- 封面暂用图标加浅色底。运营的封面图到位后再换成图片。
- 本期只改视频工作台；数字人摄影棚和视频反推不动。

## 优先级

用户提示词 > 用户上传的素材 > 场景的分镜参考。参考只补用户没写到的部分。

- 直接生成：网关把参考附在用户提示词之后，并写明「和上面的描述冲突时，一律以上面的描述为准」。用户原文一字不改。
- 提示词来自已采纳的方案时（请求带 `planId`），不再附加参考，因为方案已经参考过场景。描述框清空后不再算来自方案。
- 帮我出方案：方案模型拿到场景说明，三个方案都贴合场景，但不要求套同一个结构。面板原有的 4 个风格按钮不变，风格只管语气、节奏和画面质感。

## 记录

- 视频生成：`sceneKey`、`planId` 随请求 JSON 存在 `video_workflows.request`，不加列。两个字段为空时不写进 JSON，旧请求的幂等哈希不变。
- 视频方案：V75 加 `video_plans.scene_key`。「换一批」固定用上一批的场景；同一个 `requestKey` 换了场景会被拒绝。
- 从灵感记录打开一批方案时，工作台的场景一栏切回那批的场景。
- 未知或已下线的场景 key 按自由创作处理并记日志，不报错。
