## 认证边界

短信发送和登录继续使用既有接口；新手机号在验证后由后端自动注册。
当前后端仅支持中国大陆手机号，所以其他区号显示为未开放。
密码入口通过 `VITE_PASSWORD_LOGIN_ENDPOINT` 接入，提交 account/password，
沿用现有 TokenPair 响应与会话持久化；未配置时清晰提示使用短信登录。

微信按钮通过 `VITE_WECHAT_LOGIN_URL` 呼起服务端授权流程，服务端负责区分扫码与
微信内网页授权、生成与验证 state、回调以及与当前 tokenStore 兼容的会话交接。
仓库尚无该服务端流程，本次不把前端跳转视为完整 OAuth 登录已接通。

忘记密码提供短信登录替代路径。协议入口读取 `VITE_TERMS_URL` 和
`VITE_PRIVACY_URL`，未配置时明确提示全文未发布，不编造法律文本。
