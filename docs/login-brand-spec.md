# 登录与注册页面

面向准备进入创作工作台的品牌和门店运营人员，页面首先帮助用户完成身份验证。
采用明确、克制的科技蓝视觉，桌面为 44% 表单与 56% 品牌画板，768px 以下隐藏画板。

## 视觉约定

保留原 LoginView 的三条倾斜圆角品牌标记与「梧曜星枢」字标，全部改为蓝色系。
实现位置为 `src/views/LoginView.vue`，局部样式为 `src/login.css`，不依赖外部品牌图片。
主色 `#2563EB`，悬停 `#1D4ED8`，深蓝画板 `#0C1A31`，表单白底与文字 `#172338`。
辅助色为网格灰、浅蓝光线、微信绿与错误红；本页面不继承全局紫色主题。

领域概念为品牌资产、灵感、内容共创、增长节奏与协同工作流。独特图形是以既有品牌
标记为核心的节点连接图；不使用原版紫色轨道、虚构实时状态和租户数据、巨大营销标题。
标题和正文沿用 Noto Sans SC，微型英文标注沿用 IBM Plex Mono。4px 间距基准，
8px 控件圆角，200ms 左右的状态过渡，并尊重减少动态效果设置。

设计参数：布局变化 4、动效 3、信息密度 4、图片依赖 2、品牌保真 7。
这些参数落实为稳定双栏、短暂 Tab 过渡、单个主表单与纯代码几何画板。

## 认证边界

短信发送和登录继续使用既有接口；新手机号在验证后由后端自动注册。
当前后端仅支持中国大陆手机号，所以其他区号显示为未开放。
密码入口通过 `VITE_PASSWORD_LOGIN_ENDPOINT` 接入，提交 account/password，
沿用现有 TokenPair 响应与会话持久化；未配置时清晰提示使用短信登录。

微信按钮通过 `VITE_WECHAT_LOGIN_URL` 呼起服务端授权流程，服务端负责区分扫码与
微信内网页授权、生成与验证 state、回调以及与当前 tokenStore 兼容的会话交接。
仓库尚无该服务端流程，本次不把前端跳转视为完整 OAuth 登录已接通。

忘记密码提供短信登录替代路径。协议入口读取 `VITE_TERMS_URL` 和
`VITE_PRIVACY_URL`，未配置时明确提示全文未发布，不编造法律文本。
