# Open API 版本与弃用

当前 Phase 5 仅交付版本解析、弃用状态和配额契约的 Sandbox 实现。生产网关、持久化计数器、签名密钥和真实客户端迁移尚未接入。

## 版本策略

- 版本使用 `vN` 路径标识；同一版本的响应 Schema 只做向后兼容扩展。
- `CURRENT` 版本接收新调用；`DEPRECATED` 版本继续服务并返回迁移提示；`SUNSET` 版本拒绝调用。
- 请求未知版本时只回落到当前版本，不回落到已弃用或已下线版本。
- 下线前必须记录替代版本、公告时间、迁移文档和客户端使用量。

## 配额策略

配额按应用、租户和 Scope 维度配置窗口、基础上限与突发额度。超过额度时返回可计算的 `retryAfterMs`；不得通过前端计数器替代服务端限流。

## 交付边界

`src/domain/open-platform.js` 中的函数只验证确定性状态转换，不执行网络请求。正式开放前还需要 API Gateway、审计日志、SDK 契约测试、密钥轮换和灰度回滚演练。
