## 信息审核流程

新建信息和编辑已有信息均进入 `PENDING_REVIEW`，提交回执只表示已送审。
公开列表、详情及数据库公开读取策略仅允许有效期内的 `PUBLISHED` 信息。
审核通过时才记录公开发布时间；编辑后暂停公开展示，重新审核后恢复。

管理员在独立后台的“信息管理”查看待审核内容，填写处理依据后通过或驳回。
商家在“我的发布记录”查看状态和驳回原因，修改后可重新提交，也可撤回待审核信息。
审核接口核对管理员看到的 `updatedAt`，内容已修改或处理时拒绝旧版本决定，并保留审核记录。
被平台下线的信息继续受编辑保护，未审核即撤回的信息不能通过“重新上线”直接公开。

数据库变更使用 `V52__information_publication_review.sql`，增加待审核、驳回状态和审核意见，
允许未通过审核的信息没有公开发布时间。既有公开记录保留原状态，后续编辑进入审核流程。
升级时须先停止旧 API，再执行迁移并启动新 API，同时更新商家前端与独立管理员前端。
